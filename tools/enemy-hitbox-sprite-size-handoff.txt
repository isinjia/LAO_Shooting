enemy-hitbox-sprite-size-handoff
================================
Date: 2026-10-06
Scope: Enemy damage hit regions only (player attacks vs enemies).
Untouched: Hirume/Constantia kits, player hitR=4, bomb full-screen X.

GOAL
----
User asked for "이미지 크기 자체가 피격판정" — enemy damage hitbox covers the
drawn sprite footprint, not the old tiny center core.


FORMULAS
--------
drawSize = size * drawScale
  (drawScale defaults to 1; midboss spawn multiplies by 1.22, boss by 1.5)

BEFORE (damage hitR):
  grunt:          hitR = size * 0.24
  midboss / boss: hitR = size * 0.26
  (drawScale ignored for collision)

AFTER (damage hitR):
  all kinds:      hitR = drawSize * 0.5
                = size * drawScale * 0.5
  Circle radius = half the drawn square so a centered circle covers the sprite.

Collision path (unchanged structure):
  circle-circle: dist² < (b.r + e.hitR * hitScale)²
  beams:         capsule distance uses same e.hitR (now larger)
  dying soak:    hitScale 0.85 still applies on the new hitR
  bombs / X:     full-screen — not driven by hitR


BODY CONTACT (power-down)
-------------------------
BEFORE: (e.hitR * 0.7 + p.hitR)
AFTER:  (e.hitR * 0.38 + p.hitR)

Choice: full-sprite damage hitR makes the old ×0.7 body factor far too harsh
(especially high-drawScale grunts). Tightened to ×0.38 so body radius stays
near the old core feel when drawScale≈1, while still scaling mildly with
enlarged visuals. Documented — not matching full image on purpose for fairness.
